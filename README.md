Bloomkeeper is an original garden-defence game for the desktop browser. You are the keeper of the Heart Flower — the last flower on a dying star — holding eight waves of blight moths, rust beetles, spore hulks and the Hollow Husk with seed-light shots, a dash, sun drops, and a choice of one blessing after every wave. It plays fully offline from static files with keyboard and mouse, from title screen to win or fall, with sound synthesised live in the browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
# (the hand-in program on its own: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts)
```
